WEB PROXY SERVER - СПРАВКА

Использование:
  python main.py [ПОРТ]

Параметры:
  ПОРТ         Номер порта для прослушивания (по умолчанию 8080)

Опции:
  --help, -h   Показать эту справку

Примеры:
  python main.py              # Запуск на порту 8080
  python main.py 8888         # Запуск на порту 8888

Настройка системного прокси (Windows):
  python setup_proxy.py on 8080    # Включить системный прокси
  python setup_proxy.py off        # Выключить системный прокси
