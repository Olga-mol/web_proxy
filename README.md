# Web Proxy Server

**Автор:** Молерова Ольга

## Описание

Асинхронный прокси-сервер на Python с поддержкой HTTP и HTTPS (CONNECT туннелирование). Прокси позволяет перенаправлять трафик браузера и всей системы через себя, логирует все запросы и поддерживает Keep-Alive соединения.

### Возможности

- Поддержка HTTP (GET, POST, PUT, DELETE и любых других методов)
- Поддержка HTTPS через CONNECT туннели
- Асинхронная обработка множества соединений
- Keep-Alive и переиспользование соединений
- DNS кэширование для ускорения работы
- Логирование всех запросов в файл и консоль
- Системная настройка прокси (Windows)

## Установка

### Требования

- Python 3.8 или выше
- pip

### Установка зависимостей

```bash
pip install pytest pytest-asyncio pytest-cov
```

## Запуск прокси-сервера
```bash
python main.py [порт]
```

### Вызов справки
```bash
python main.py --help
python main.py -h
```

## Настройка прокси

### Способ 1 — Ручная настройка:

HTTP прокси: localhost
Порт: 8080

### Способ 2 — Запуск Chrome с прокси:

```bash
chrome.exe --proxy-server=localhost:8080
```

### Способ 3 — Автоматическая настройка Windows:

```bash
python setup_proxy.py on 8080
```
Отключение системного прокси (Windows)
```bash
python setup_proxy.py off
```

# Логирование
Логи записываются в два места:

Консоль и файл proxy.log

### Формат лога:

text
2026-05-27 10:00:00 | 127.0.0.1 | GET | example.com/ | 200 | 12560 байт | 150 мс
